# sales-The Sales Data Analysis System is designed to
simplify the process of storing, managing, and analyzing sales-related
information in an efficient and user-friendly manner.
This project is a desktop-based application developed using Python
(Tkinter GUI) and SQLite Database. It provides an interactive interface
for users to perform various operations such as adding, updating,
deleting, and viewing sales records. The system also includes advanced
features like data visualization, charts, reports, and secure login with OTP
verification.
The main aim of this system is to convert raw sales data into useful
information that helps users understand trends, identify top-performing
products, and make better business decisions. By using this system,
manual work is reduced, accuracy is improved, and time is saved.
